# Data sources

macro-collector downloads data from the sources below with **your own** keys and settings, for **your own** use. The code is open (MIT). The data is not (see [Data is not redistributed](#data-is-not-redistributed)).

Terms were checked on the official pages on 2026-11-16 (and earlier, during the phase where each source was added). They are summarised here, not quoted in full, and this is not legal advice. Terms change, so read the linked page before you rely on it. Where a page could not be read, the row says **terms not verified**.

"Demo" is whether the public demo site (`macroctl site --demo`) may show the data. Only series listed in `dashboard.demo_allow`, EDGAR facts, Treasury data and official calendars get through. Everything else is shown as "Hidden in the demo".

Request pacing is what the code does. "Limit" is what the provider publishes.

## Yahoo Finance: unofficial endpoint, personal use

- `query1.finance.yahoo.com/v8/finance/chart` has no documentation and no API contract. It can change or disappear without notice. That is why Yahoo is a non-critical source (D7): when it fails, the export falls back to FRED series where configured.
- The [Yahoo Terms of Service](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html) prohibit collecting data by automated means without Yahoo's prior permission (section 2(d)) and commercial use (section 2(e)). [Yahoo Finance help](https://help.yahoo.com/kb/finance-for-web/SLN2310.html) says the data must not be redistributed. Most quotes come from ICE Data Services and other exchanges' providers, often delayed, and are "not intended for trading or investing purposes".
- If you enable `yahoo`, you do so at your own risk and for personal use only. Keep request volume low (the code waits 1 s between requests). Yahoo prices never appear in the demo.

## Telegram: third-party content, web mode

- The collector reads **public** channels through the web preview `t.me/s/<channel>` (D12): no account, no API key, no MTProto session.
- The [Telegram Terms of Service](https://telegram.org/tos) prohibit data scraping, and the [content licensing terms](https://telegram.org/tos/content-licensing) prohibit access to user content beyond ordinary use and using it to train AI models. Reading channels this way may break those terms. Use it only for your own reading, at a low volume (one page every 2 s), and don't build datasets from it.
- Posts belong to their authors. They are stored to be summarised for your own agents and are never published: Telegram content is closed in the demo, and `testdata/` holds only trimmed, anonymised fragments of the page structure.
- Posts are classified by Gemini (see above). On the free tier Google may use what you send, so don't add private channels or personal data.

## Data is not redistributed

Decision D21: **the code is open, the data is not distributed.**

- Every user connects their own keys (`.env`, see `.env.example`) and downloads the data themselves under each provider's terms.
- The repository contains no downloaded data beyond test fixtures. `testdata/` holds recorded responses of open sources as-is; third-party text (Telegram, earnings-call transcripts, IR pages, RSS) is trimmed or anonymised to what the tests read, and issuer workbooks keep only the sheets the parser reads. Small market-data responses (Yahoo, Cboe, prediction markets, Nasdaq, STOXX, ZEW) are kept as recorded, for parser tests only.
- The weekly export (`exchange/`) is for your own Claude Projects and goes to **your private** repository (`git.repo`). Don't make it public: it contains Yahoo, ICE, S&P, UMich, Cboe and Telegram content.
- The public demo site shows only open data (D24): public-domain FRED series from `dashboard.demo_allow`, Treasury, EDGAR facts, ECB, the Bundesbank's own series, Eurostat and official calendars, with the sources named in the footer. Everything else is shown as "Hidden in the demo". The build is checked before every push and is not published if it contains anything outside `demo_allow`.
- Before adding a series to `demo_allow`, check its licence (for FRED: `/fred/series/tags`, the word "Copyright" in the notes).
